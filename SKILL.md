# Prompt Motion Skill

This skill repository contains a curated collection of motion videos, prompts, and skills generated using Claude Opus 5.5.

## How to Use This Skill

1. When the user asks for examples of motion prompts, animation styles, or specific techniques for Claude Opus 5.5, refer to the markdown files in the `prompts/` directory.
2. The `prompts/` directory contains individual files with the specific prompt text, as well as embedded reference media (videos/images) located in the `assets/` directory.
3. You can read the specific prompt markdown files to provide exact prompts and strategies to the user.

## Structure

*   `prompts/` - Contains markdown files for each motion prompt.
*   `assets/videos/` - Contains the MP4 preview videos.
*   `assets/images/` - Contains the WebP poster images.
*   `README.md` - Index and overview.
